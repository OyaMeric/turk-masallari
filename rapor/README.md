# Rapor

Bu klasörü öğrenci kendisi dolduracak.

İçine konacaklar:

- `rapor.tex` — LaTeX şablonu
- `rapor.pdf` — derlenmiş rapor

## Raporda bulunması gerekenler

- Projenin tanıtımı ve amacı
- Masal listesi ve **seçim gerekçesi** (çeşitlilik hedefi — `README.md` içinde özetlendi)
- **Her masalın kaynağı** (ödev şartı) — `kaynaklar.md` dosyasındaki tablo
- Tasarım kararlarının gerekçesi — `tasarim-notlari.md`
- Kodun anlatımı — `kod-haritasi.md`
- Yapay zekâ kullanımının dökümü — `yz-kullanimi.md`
- Sunum videosunun bağlantısı
